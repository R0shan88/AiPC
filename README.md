## 🧭 What Is AiPC?

AiPC is an open-source application that gives an AI agent "this" — a real PC to work with. Instead of an AI that can only chat with you, AiPC is designed around the idea of handing your agent an actual computer environment so it can do real work on a real desktop.

The project is built for everyday people, not just programmers. If you have ever wanted to see what happens when an AI agent is given genuine access to a machine — files, windows, applications, the whole desktop — AiPC is the tool that makes that possible.

AiPC connects to the AI models you already know and trust. Whether you prefer Claude, Gemini, GPT, Kimi, Qwen, or another OpenAI-compatible model, the goal is the same: your agent gets a real PC, and you get to watch it work.

## ✨ What Makes AiPC Useful

AiPC was built for a world where AI agents do more than answer questions. Here is what that means in plain language:

**Your agent gets a genuine computer.** Rather than being limited to a text box, the agent is given a real PC environment to operate within. It can interact with the desktop the same way a person would.

**You stay in charge.** AiPC runs on your own Windows machine. You decide when it starts, what it can access, and when it stops. Nothing happens behind your back on someone else's server.

## 🧩 How AiPC Works, In Simple Terms

Think of AiPC as a bridge with two ends.

On one end sits your AI agent — the model that does the thinking. On the other end sits a real computer — the thing that does the doing. AiPC is the bridge that connects them.

When your agent decides it needs to do something, it sends a request across the bridge. AiPC relays that request to the real PC and reports back what happened. The agent then decides what to do next, based on what it learned. This back-and-forth continues until the task is finished.

This is what people mean when they talk about an "agent" rather than a chatbot. A chatbot answers. An agent acts. AiPC is what makes acting possible.

The bridge itself is built on MCP, an open standard. Because it is open, AiPC can connect to MCP tools and MCP servers from other projects too — not just the ones that ship with AiPC.
